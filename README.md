# 모두의 화장실 만들기

전교조 성소수자위원회의 모두의 화장실(성중립 화장실) 홍보용 웹게임입니다.
20×15 칸 보드에 변기, 세면대, 손잡이, 점자블록 등을 설치하고 **▶ 테스트하기**를 누르면
이용객 5명이 차례로 들어와 화장실을 이용해 봅니다. 성공하면 기쁜 표정, 실패하면 슬픈 표정과 이유가 나옵니다.

휴대폰, 패드, PC 브라우저에서 모두 동작합니다. 설치할 것은 없습니다.

## 조작

- 보드 전체가 하나의 모두의 화장실(1인 또는 보호자 동반 공간)입니다. 처음에는 빈 공간에서 시작합니다.
- 이용객은 오른쪽 아래 **입구**(4칸 폭)로 들어옵니다.
- 설비를 고르고 보드를 누르면 그 자리에 놓입니다. 놓은 설비를 끌어서 옮기고, 위쪽 **⟳ 돌리기**로 방향을 바꿉니다. 변기는 방향을 바꿀 수 없습니다.
- 점자블록은 끌어서 바닥에 깔고, 설비 아래에도 깔 수 있습니다. 점자 안내판은 바깥 벽에 붙입니다.
- 두 손가락으로 확대하거나 옮길 수 있습니다. PC에서는 마우스 휠로 확대하고 ✋ 버튼을 켜서 옮깁니다.
- 위쪽 이용객을 누르면 그 사람에게 필요한 것이 보입니다.
- 꾸민 화장실은 브라우저에 자동 저장됩니다.

## 설비 크기 (가로 × 세로, 1칸 ≈ 25cm)

| 설비 | 크기 | 방향 바꾸기 |
|---|---|---|
| 변기 | 2 × 3 | 안 됨 |
| 세면대, 낮은 세면대 | 3 × 2 | 됨 |
| 기저귀 교환대 | 4 × 3 | 됨 |
| 유아 의자 | 2 × 3 | 됨 |
| 오스토미 세척대 | 2 × 2 | 됨 |
| 손잡이 | 3 × 1 | 됨 |
| 점자블록, 점자 안내판 | 1칸씩 | - |

크기는 `js/config.js`의 `w`, `h`로 바꿀 수 있습니다.

## 판정 규칙

"닿는다"는 이용객이 설비 바로 옆 칸까지 갈 수 있다는 뜻입니다.
휠체어는 3칸 폭, 다른 이용객은 2칸 폭의 길이 있어야 지나갈 수 있습니다.

| 이용객 | 조건 |
|---|---|
| 휠체어 이용자 | 3칸 폭 길로 변기 옆까지, 휠체어가 닿는 6×6칸 빈 공간, 변기 바로 옆 손잡이, 낮은 세면대 |
| 아이와 함께 온 보호자 | 변기, 유아 의자나 기저귀 교환대, 세면대 |
| 트랜스젠더·논바이너리 이용자 | 변기, 세면대 (성별을 묻지 않는 1인 공간이라 따로 필요한 것이 없음) |
| 장루·요루 이용자 | 변기, 오스토미 세척대, 세면대 |
| 시각장애인 | 입구부터 변기 옆까지 이어진 점자블록, 입구에서 2칸 이내 벽에 점자 안내판, 변기, 세면대 |

규칙 코드는 `js/logic.js`의 `rules`에 있습니다.

## 문구와 그림 바꾸기

- 설비 이름·크기·설명, 이용객 이름과 필요한 것 목록은 `js/config.js`에서 고칩니다.
- 그림은 파일만 넣으면 바뀝니다. 파일이 없으면 임시 그림(이모지와 도형)을 씁니다.
  - 설비: `assets/items/<id>.png`. 기본 방향(벽이 위쪽) 기준 `가로칸×64` × `세로칸×64` px. 예: 변기 128×192px. 방향을 돌리면 그림도 함께 돌아갑니다.
  - 바닥·벽·입구·점자블록·점자 안내판: `floor.png`, `wall.png`, `entrance.png`, `tactile.png`, `braille.png` (64×64px)
  - 이용객: `assets/visitors/<id>_normal.png`, `<id>_happy.png`, `<id>_sad.png`
  - id 목록은 `js/config.js`에 있습니다. 배경이 투명한 PNG를 권장합니다.

## 개발

빌드 도구 없이 HTML, CSS, JavaScript만 씁니다.

```bash
python3 -m http.server 8000   # http://localhost:8000 에서 확인
node tests/logic.test.js      # 판정 규칙 테스트
```
