# 모두의 화장실 만들기

전교조 성소수자위원회의 모두의 화장실(성중립 화장실) 홍보용 웹게임입니다.
30×20 칸 보드에 벽, 문, 변기, 세면대, 손잡이 등을 설치하고 **▶ 테스트하기**를 누르면
이용객 5명이 차례로 들어와 화장실을 이용해 봅니다. 성공하면 기쁜 표정, 실패하면 슬픈 표정과 이유가 나옵니다.

휴대폰, 패드, PC 브라우저에서 모두 동작합니다. 설치할 것은 없습니다.

## 조작

- 왼쪽(세로 화면에서는 아래쪽) 팔레트에서 물건을 고르고 보드를 누르면 설치됩니다. 끌면 여러 칸에 이어서 설치됩니다.
- 두 손가락으로 확대하거나 옮길 수 있습니다. PC에서는 마우스 휠로 확대하고 ✋ 버튼을 켜서 옮깁니다.
- 위쪽 이용객을 누르면 그 사람에게 필요한 것이 보입니다.
- 꾸민 화장실은 브라우저에 자동 저장됩니다.

## 판정 규칙

벽, 칸막이, 문으로 둘러싸인 공간을 하나의 **칸**으로 봅니다. 입구에서 갈 수 있는 칸 중에
조건을 모두 갖춘 칸이 하나라도 있으면 성공입니다.

| 이용객 | 조건 |
|---|---|
| 휠체어 이용자 | 입구에서 칸까지 길과 문이 2칸 폭, 칸 안에 2×2 빈 공간, 변기 바로 옆 벽에 손잡이, 낮은 세면대 |
| 아이와 함께 온 보호자 | 빈 바닥 6칸 이상인 칸, 칸 안에 유아 의자나 기저귀 교환대, 세면대 |
| 트랜스젠더·논바이너리 이용자 | 성별 표시가 없는 칸, 아래 뚫린 칸막이가 없는 칸, 세면대 |
| 장루·요루 이용자 | 칸 안에 오스토미 세척대, 세면대 |
| 시각장애인 | 입구부터 칸 문 앞까지 이어진 점자블록, 칸 문 옆 점자 안내판, 세면대 |

모든 이용객은 변기가 있는 칸에 들어갈 수 있어야 합니다. 규칙 코드는 `js/logic.js`의 `rules`에 있습니다.

## 문구와 그림 바꾸기

- 물건 이름과 설명, 이용객 이름과 필요한 것 목록은 `js/config.js`에서 고칩니다.
- 그림은 파일만 넣으면 바뀝니다. 파일이 없으면 임시 그림(이모지와 도형)을 씁니다.
  - 물건: `assets/items/<id>.png` (예: `toilet.png`, `grabBar.png`, `wall.png`, `floor.png`, `entrance.png`)
  - 이용객: `assets/visitors/<id>_normal.png`, `<id>_happy.png`, `<id>_sad.png`
  - id 목록은 `js/config.js`에 있습니다.
  - 1칸 = 64×64px, 배경이 투명한 PNG를 권장합니다.

## 개발

빌드 도구 없이 HTML, CSS, JavaScript만 씁니다.

```bash
python3 -m http.server 8000   # http://localhost:8000 에서 확인
node tests/logic.test.js      # 판정 규칙 테스트
```
