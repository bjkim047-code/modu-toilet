# 모두의 화장실 만들기

전교조 성소수자위원회의 모두의 화장실(성중립 화장실) 홍보용 웹게임입니다.
20×15 칸 보드에 변기, 세면대, 손잡이, 점자블록 등을 설치하고 **▶ 테스트하기**를 누르면
이용객 5명이 차례로 들어와 화장실을 이용해 봅니다. 성공하면 기쁜 표정, 실패하면 슬픈 표정과 이유가 나옵니다.

휴대폰, 패드, PC 브라우저에서 모두 동작합니다. 설치할 것은 없습니다.

## 조작

- 보드 전체가 하나의 모두의 화장실(1인 또는 보호자 동반 공간)입니다. 처음에는 빈 공간에서 시작합니다.
- 이용객은 오른쪽 아래 **입구**(4칸 폭)로 들어옵니다.
- 설비를 고르고 보드를 누르면 그 자리에 놓입니다. 놓은 설비를 끌어서 옮기고, 위쪽 **⟳ 돌리기**로 방향을 바꿉니다. 변기는 방향을 바꿀 수 없습니다.
- 점자블록은 끌어서 바닥에 깔고, 설비 아래에도 깔 수 있습니다. 점자 안내판은 바깥 벽에 붙입니다.
- 두 손가락으로 확대하거나 옮길 수 있습니다. PC에서는 마우스 휠로 확대하고 ✋ 버튼을 켜서 옮깁니다.
- 위쪽 이용객을 누르면 그 사람에게 필요한 것이 보입니다.
- 꾸민 화장실은 브라우저에 자동 저장됩니다.

## 시험하는 방법

- **이용객 누르기**: 그 이용객을 고르고, 필요한 것을 아래 안내줄에 보여 줘요.
- **▶ 테스트하기**: 고른 이용객 한 명만 시험해요. 결과는 그 이용객 칸에 표정으로 남아요.
- **🏁 도전하기**: 5명이 차례로 이용하고 마지막에 결과를 발표해요.
- 이용객은 ① 변기 → ② 각자 필요한 설비(장루·요루: 오스토미 세척대, 보호자: 기저귀 교환대나 유아 의자) → ③ 맞는 세면대(휠체어 이용자·보호자: 낮은 세면대, 그 밖: 세면대) → ④ 입구 순서로 움직이고, 입구에서 결과를 보여 줘요. 시각장애인은 ①을 점자블록을 따라서만 가요.

## 설비 크기 (가로 × 세로, 1칸 ≈ 25cm)

| 설비 | 크기 | 방향 바꾸기 |
|---|---|---|
| 아동용 변기 | 2 × 2 | 두 방향 |
| 변기 | 2 × 3 | 두 방향(오른쪽 위 벽, 왼쪽 위 벽) |
| 세면대 | 3 × 2 (벽걸이: 뒤쪽 벽 바로 옆, 벽 가운데 높이, 바닥을 막지 않음) | 붙은 벽에 따라 자동, 모서리에서만 돌리기 |
| 낮은 세면대 | 3 × 2 (벽걸이: 뒤쪽 벽 바로 옆, 벽 아래 단, 바닥을 막지 않음) | 세면대와 같음 |
| 기저귀 교환대 | 3 × 2 (벽걸이: 뒤쪽 벽 바로 옆, 벽 가운데 높이) | 세면대와 같음 |
| 유아 의자 | 1 × 2 (벽걸이: 뒤쪽 벽 바로 옆, 벽 가운데 높이) | 세면대와 같음 |
| 오스토미 세척대 | 3 × 2 (실제 약 60 × 65cm, 벽 판 포함) | 두 방향(오른쪽 위 벽, 왼쪽 위 벽) |
| 손잡이 | 1 × 3 | 됨 |
| 휴지걸이 | 1 × 1 (뒤쪽 벽 바로 옆 칸, 벽 가운데 높이) | 붙은 벽에 따라 자동, 모서리 칸에서만 돌리기 |
| 수건걸이 | 벽을 따라 2칸 (뒤쪽 벽 바로 옆, 벽 가운데 높이) | 휴지걸이와 같음 |
| 비상벨 | 1 × 1 (뒤쪽 벽 바로 옆 칸, 높이 아래·가운데·위 중 선택) | 휴지걸이와 같음 |
| 점자블록, 점자 안내판 | 1칸씩 | - |

크기는 `js/config.js`의 `w`, `h`로 바꿀 수 있습니다.

높이 층: 바닥 설비, 그리고 벽에 붙는 물건(`mount: true`, 세면대·낮은 세면대·기저귀 교환대·유아 의자·휴지걸이·수건걸이·비상벨)의 높이 단 1(아래)·2(가운데)·3(위)이 각각 다른 층입니다. 다른 층끼리는 같은 칸에 겹쳐 놓을 수 있고, 같은 층끼리는 겹칠 수 없습니다. 낮은 세면대는 아래 단, 세면대·기저귀 교환대·유아 의자·휴지걸이·수건걸이는 가운데 단에 고정이고, 비상벨은 보드 아래 **붙일 높이** 버튼이나 선택 후 **⇕ 높이** 버튼으로 단을 고릅니다. 벽에 붙는 물건은 바닥을 막지 않아 이용객이 그 칸을 지나갈 수 있습니다.

## 판정 규칙

"닿는다"는 이용객이 설비 바로 옆 칸까지 갈 수 있다는 뜻입니다.
휠체어는 3칸 폭, 다른 이용객은 2칸 폭의 길이 있어야 지나갈 수 있습니다.

| 이용객 | 조건 |
|---|---|
| 휠체어 이용자 | 3칸 폭 길로 변기 옆까지, 휠체어가 닿는 6×6칸 빈 공간, 변기 바로 옆 손잡이, 낮은 세면대 |
| 아이와 함께 온 보호자 | 변기, 아동용 변기, 유아 의자나 기저귀 교환대, 낮은 세면대 |
| 트랜스젠더·논바이너리 이용자 | 변기, 세면대 (성별을 묻지 않는 1인 공간이라 따로 필요한 것이 없음) |
| 장루·요루 이용자 | 변기, 오스토미 세척대, 세면대 |
| 시각장애인 | 입구부터 변기 옆까지 이어진 점자블록, 입구에서 2칸 이내 벽에 점자 안내판, 변기, 세면대 |

규칙 코드는 `js/logic.js`의 `rules`에 있습니다.

## 문구와 그림 바꾸기

- 설비 이름·크기·설명, 이용객 이름과 필요한 것 목록은 `js/config.js`에서 고칩니다.
- 그림은 파일만 넣으면 바뀝니다. 파일이 없으면 임시 그림(이모지와 도형)을 씁니다.
  - 설비: `assets/items/<id>.png`. 기본 방향 기준 `가로칸×128` × `세로칸×128` px. 예: 변기 256×384px. 방향을 돌리면 그림도 함께 돌아갑니다.
  - 바닥·벽·입구·점자블록·점자 안내판·비상벨: `floor.png`, `wall.png`, `entrance.png`, `tactile.png`, `braille.png` (128×128px)
  - 지금 들어 있는 그림: 변기, 손잡이, 휴지걸이, 비상벨
  - 마름모 보기용 방향별 그림: `assets/items/<id>_iso_a.png`(왼쪽 아래를 보는 모습, 오른쪽 위 벽에 붙음)와 `<id>_iso_b.png`(오른쪽 아래를 보는 모습, 왼쪽 위 벽에 붙음). 있으면 마름모 보기에서 이 그림을 씁니다. 마름모 보기 점자블록은 `tactile_iso_a.png`(마름모 타일 한 장)를 칸마다 깝니다. 무지개 스티커(꾸미기용, 벽 2칸, 높이 선택)도 있습니다. 지금은 변기, 세면대, 낮은 세면대, 오스토미 세척대, 기저귀 교환대, 유아 의자, 손잡이, 휴지걸이, 수건걸이, 비상벨, 점자 안내판이 있습니다. 점자 안내판처럼 바깥 벽 칸에 붙는 물건은 a가 가로로 뻗은 벽(위·아래 테두리), b가 세로로 뻗은 벽(왼쪽·오른쪽 테두리)용입니다. a는 기본 방향, b는 한 번 돌린 방향의 칸 모양에 맞춰 그립니다.
  - 이용객: `assets/visitors/<id>_walk_a.png`(오른쪽 위로 가는 뒷모습), `<id>_walk_b.png`(왼쪽 위로 가는 뒷모습), `<id>_front_a.png`(↘ 오른쪽 아래로 갈 때 앞모습), `<id>_front_b.png`(↙ 왼쪽 아래로 갈 때 앞모습, 없으면 뒷모습 유지), `<id>_happy.png`(성공), `<id>_sad.png`(실패), `<id>_normal.png`(그 밖의 기본). 이용객 5명 모두 그림이 있습니다.
  - id 목록은 `js/config.js`에 있습니다. 배경이 투명한 PNG를 권장합니다.

## 개발

빌드 도구 없이 HTML, CSS, JavaScript만 씁니다.

```bash
python3 -m http.server 8000   # http://localhost:8000 에서 확인
node tests/logic.test.js      # 판정 규칙 테스트
```

## 배포 (GitHub Pages)

`index.html`의 CSS·JS 주소 끝에 `?v=버전`을 붙여 두었습니다. 파일을 고친 뒤 이 값을 바꾸면 브라우저가 예전 파일을 쓰지 않고 새로 받습니다.

저장소 Settings → Pages → Branch를 `main`, 폴더를 `/ (root)`로 정하고 저장하면
`https://<계정>.github.io/modu-toilet/` 주소로 공개됩니다.
